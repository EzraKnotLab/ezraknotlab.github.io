设计哲学：原研哉——空，而非简

从“专家水平代表人类水平”这个实用标准来看，Fable 5 + Opus 5 确实是一个比较清晰的分水岭——它们开始在多个经济上真正有价值的领域，持续、可靠地达到或超越人类专家。

Opus 5 和 Fable 5 的 Elo 分数已经明显高于人类专家基线，很多任务上“赢或平”的比例接近或超过 50%。

taste 的门槛不低，这个确实是。很多访谈类podcast，就像JRE里面，名人、艺术家、作家啥的，几乎就是一集里面凝练前半生的精华了，而且作品也随着一起进化。

但是好的设计是共通的，不分文理，人人相通——比如软件产品的交互习惯，就像是Claude的点击发送这些按钮和logo、标志、符号，页面的设计、海报宣发、官网页面的字体风格排版等等，这些很多都是特别高级的工程师设计师做的。尤其是像Anthropic这种要塑造一种文化的公司，所有用的字体都是重新设计的，在文理方面都有创新突破，包括像很多拿奖的美剧或者电影游戏啥的，那些附属产品、背景音乐也花大价钱打造，也能够得奖。

艺术设计里很多taste确实没法量化，但也不是完全没法描述——比如一个学派、一种画风，最基本的核心理念和规则，其实还是能用文字描述出来留存复利。真正难的是细节和习惯，那部分还是得靠人一步步"渲染"，像教小孩一样耳濡目染，慢慢调，在基础款和理想款之间不断插值，很多skill本质上干的就是这个——先把案例喂进去丰富细节，下一次创新还是要在这个基础上自己花功夫调整，只不过是站在之前所有尝试次数的肩膀上，不用再从头来过。

Iris Murdoch在《The Sovereignty of Good》里把道德的核心定义为"注意力的质量"（quality of attention）——这句话放在这儿，几乎就是taste的哲学定义。

MCP MHS

MCP（Model Context Protocol，模型上下文协议）Anthropic 在 2024年11月25日 正式开源并发布。
由 Anthropic 工程师 David Soria Parra 和 Justin Spahr-Summers 创建。
它是一个开放标准，旨在标准化 AI 助手（如 LLM）与外部工具、数据源、系统的连接方式，解决”N×M 集成问题”（每个模型/应用都要为每个工具单独写适配）。
后来被广泛采用，并在 2025年底捐赠给 Linux 基金会下的 Agentic AI Foundation 进行中立治理，但最初完全是 Anthropic 提出并开源的。

来源：Introducing the Model Context Protocol

MHS（Model Hardware Standard，模型硬件标准）Anthropic 在 2026年8月27日 发布研究预览（research preview）。
起源于 Anthropic 与 HHMI Janelia Research Campus 的合作，目标是让 AI agent 能安全、统一地操作物理设备（如显微镜、液体处理仪、机械臂、量子计算机激光等）。
它是 MCP 的硬件层延伸：MCP 解决软件/数据连接，MHS 解决物理硬件的标准化驱动、状态描述和安全约束。
Anthropic 主导推广，目前处于有限合作伙伴预览阶段，计划在安全评估后开源。它明确提到可与 MCP 等标准协议配合使用，且是 model-agnostic（不绑定特定模型）。

来源：Previewing the Model Hardware Standard

简单来说：MCP = Anthropic 首创的“AI 连软件/工具”的通用协议。
MHS = Anthropic 主导提出的“AI 连物理硬件”的新标准（与研究机构合作）。

从MCP到MHS，其实是木桶理论的两条路径Anthropic都在做：MCP是长板，本身就是定义了行业标准、直接领军；MHS是补短板，把物理硬件这块此前没人系统化的地方接管过来，克服瓶颈。要么做长板、行业领军，要么专注短板、克服瓶颈——两手都没放。
很值得读，不一定非要用到 但是post-AI era的很多设计和创新的思路都需要好好思考。

NYC Mayor

↩️
Zohran Mamdani 现在是纽约市第112任市长——首位穆斯林市长，首位南亚裔市长，一个多世纪以来最年轻的市长（34岁），2026年1月1日就职时手按《古兰经》宣誓，纽约市历史上第一次。他1991年生于乌干达坎帕拉，父亲Mahmood Mamdani是哥伦比亚大学的后殖民研究学者，母亲Mira Nair是《季风婚礼》的导演，中间名Kwame取自加纳独立领袖恩克鲁玛。7岁随家人经开普敦落脚纽约，布朗克斯科学高中，Bowdoin College非洲研究学位，毕业后做过防止止赎的住房顾问，也短暂以”Young Cardamom”的艺名玩过说唱。2021到2025年做纽约州众议员，代表皇后区阿斯托利亚，2024年10月以民主社会主义者身份、几乎无人看好的姿态宣布竞选市长，2025年6月初选爆冷击败科莫，11月大选以约五成得票拿下全局。

他的政治天花板大概就到这了——宪法第2条要求总统必须是natural-born citizen，他1991年在乌干达出生、2018年才归化入籍，没有资格竞选总统或副总统，他自己也说宪法这条挺好，没打算推动修宪。这让纽约市长这个位置的分量变得不太一样：不是通往更高职位的跳板，而本身就是终点。任内已经落地的东西：联合州政府推进全民托儿、租金稳定公寓冻结租金、”Block by Block”可负担住房计划，民调里年轻人和民主党人对他支持率明显偏高。他本人也住在阿斯托利亚的租金稳定公寓里，2025年经约会软件认识现在的妻子Rama Duwaji（叙利亚裔艺术家）——政策不是喊出来的，是他自己也在用的那套系统。

他信奉什叶派伊斯兰教（十二伊玛目/Khoja传统，来自父亲一系），但成长在跨信仰家庭——母亲这边是印度教，他从小过排灯节、洒红节、兄妹节。他自己的说法是”同时持有”这两重身份，不是二选一，但真正走进公共身份的还是穆斯林这一面：父亲多年研究殖民主义和穆斯林身份政治（写过《好穆斯林，坏穆斯林》），后9/11语境下公开认穆斯林身份本身带有政治意味，也跟他关注巴勒斯坦议题的立场自洽。印度教身份在美国南亚社群里其实更”主流”、政治资本更现成，他没选那条路，这个选择本身就说明他更看重身份政治的立场价值，而不是路径最省力的那个选项。

预测市场现在把他列进2026年《时代》年度人物的热门候选，Polymarket和Kalshi上的赔率大概在20%到36%之间浮动，同一梯队的还有新教宗利奥十四世、特朗普、马斯克。这事年底才揭晓，但一个宪法上不能选总统的市长能进这份候选名单，已经说明影响力和权力天花板从来不是一回事。
